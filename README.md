## Projects

**[Rift Index](https://andrewjohnroy.com)** — Next.js · TypeScript · React · Riot Games API

League of Legends champion and player lookup. Browses all 173 champions on the live patch with filtering by class, kit, base stats and skins, and looks up any player's rank, champion mastery and recent matches across 17 regions. Built on the Riot Games API and Data Dragon CDN behind a documented caching layer that keeps requests inside Riot's rate limits, with a public API reference page.

**Mobile phone shop** — React · Node.js · Express · MongoDB

Full-stack storefront with a React front end, an Express API and MongoDB persistence, covering product data, routing and server-side logic.

**Online bookshop** — Vanilla JavaScript · HTML · CSS

Built with no frameworks or libraries — rendering, event binding and cart state handled directly against the DOM API.

**Wellbeing app** — React Native · Expo · SQLite

Group project for COMP5216 Mobile Computing. Gamified wellbeing tracker built around an avatar that responds to daily physical, mental and social tasks, with social encouragement between users. Uses expo-location for run and route logging, expo-camera for QR-code friend adding, and expo-sensors for step counting.
